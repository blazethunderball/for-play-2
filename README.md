# For Play
Static installable PWA for two players sharing one phone.

## Cloudflare Pages
Put all files in the repository root. Set Framework preset to **None**, build command to `exit 0`, and build output directory to `.`.

## Android installation
Open the deployed HTTPS URL in Chrome, then browser menu → Install app / Add to Home screen.

Settings are saved locally on the device. Timer durations can be selected in multiples; the app randomly chooses an enabled duration and an action each turn. Alarm can be switched off in Game Settings.
Action List Progression defaults to **Rolling Lists**. Choose Separate Lists, Rolling Lists, or Cumulative Lists in Game Settings. The preference is saved locally.
